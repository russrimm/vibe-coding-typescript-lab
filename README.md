# Vibe Coding in TypeScript: A Hands-On Lab

A comprehensive, step-by-step lab guide for learning **vibe coding** with GitHub Copilot, TypeScript, React, Vite, and Tailwind CSS — designed for non-developer professionals.

## 🎯 What You'll Build

- A modern web application using **Vite + React + TypeScript + Tailwind CSS**
- Fully configured **GitHub Copilot** with custom instructions and MCP servers
- **CI/CD pipeline** with GitHub Actions
- **Azure Static Web Apps** deployment
- *(Optional)* **Power Apps code app** published to Power Platform

## 📚 Lab Contents

This lab covers 9 complete modules:

1. **Environment Setup** — WSL 2, Ubuntu on Windows
2. **VS Code & Extensions** — VS Code Insiders with 10+ essential extensions
3. **GitHub Account & Git** — SSH keys, GitHub CLI, Azure CLI
4. **MCP Servers** — 5 Model Context Protocol servers (Microsoft Learn, Context7, Azure, GitHub, Playwright)
5. **Copilot Customization** — Custom instructions, path-specific rules, reusable prompts
6. **Vibe Code a Project** — Build a full app using Copilot Agent Mode
7. **Deploy to Azure** — Azure Static Web Apps with SPA routing
8. **CI/CD with GitHub Actions** — Automated testing, linting, and deployment
9. **(Optional) Power Apps Code App** — Publish to Power Platform as a managed business app
